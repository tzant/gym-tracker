# 🏋️ GymTracker — Дневник тренировок

Красивое мобильное веб-приложение для записи результатов тренировок в спортзале.

![React](https://img.shields.io/badge/React-18-blue) ![TypeScript](https://img.shields.io/badge/TypeScript-5-blue) ![Tailwind](https://img.shields.io/badge/Tailwind-3-green) ![PWA](https://img.shields.io/badge/PWA-ready-lime)

## ✨ Возможности

- 📝 **Запись тренировок** — вес, повторения, подходы для каждого упражнения
- 📋 **Библиотека** — 45 упражнений по 7 группам мышц
- 📈 **Прогресс** — графики объёма, частоты, личные рекорды
- 📅 **История** — все тренировки по месяцам
- ⏱️ **Таймер отдыха** — 90 секунд между подходами
- 💾 **Офлайн** — работает без интернета (PWA)
- 📱 **Мобильный дизайн** — оптимизирован для Android/iOS

## 🎨 Дизайн

- Чёрно-серая цветовая схема с салатовыми акцентами
- Минималистичный премиальный интерфейс
- Плавные анимации и переходы
